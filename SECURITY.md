# Security Policy

## Supported Versions

ArmForge is in active phased development. Security fixes will be applied to the
latest mainline branch first.

## Reporting a Vulnerability

Do not open public issues for undisclosed vulnerabilities.

Report security concerns privately to the maintainers with:

- affected component
- impact assessment
- reproduction details
- any proposed mitigation

Maintainers will acknowledge receipt, assess severity, and coordinate a fix and
disclosure timeline.

## Scope Notes

Phase-00 does not ship optimized kernels or privileged services. Security
considerations are still relevant for:

- supply chain and dependency hygiene
- CI and container configuration
- benchmark input handling
- integration patch review
